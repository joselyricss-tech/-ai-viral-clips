
# AI Viral Clips 🚀

Plataforma de inteligencia artificial para convertir videos en clips cortos y virales.

## Funciones del proyecto

- Analizar videos publicados de YouTube.
- Preparar soporte para transmisiones en vivo.
- Detectar momentos destacados.
- Crear clips verticales 9:16.
- Generar subtítulos automáticos.
- Preparar contenido para TikTok, Instagram Reels y YouTube Shorts.
- Administrar proyectos y clips desde un panel web.

## Tecnologías

- Next.js
- React
- TypeScript
- Python
- FastAPI

## Instalación

### Backend

Entrar en la carpeta backend:

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend

En la carpeta principal:

```bash
npm install
npm run dev
```

Abrir http://localhost:3000
